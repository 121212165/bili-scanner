# B站扫榜助手 · 低粉爆文探测器

在 B站搜索页 / 热门页 / 排行榜页给视频打标：**播放 / 粉丝 = 爆文率**，高亮低粉爆文，支持关键词命中标记与当日累积 CSV 导出。用于小说推文/短剧赛道的选题扫榜。

## 纯匿名原则（硬约束）

- **不登录**：只用 B站公开接口，无需账号
- **不携带 Cookie**：油猴版 `GM_xmlhttpRequest({ anonymous: true })`；扩展版 `fetch({ credentials: 'omit' })`
- **零后端、零收集**：无任何服务器，数据只存浏览器本地 localStorage
- **匿名限速**：串行请求 + 300ms 固定间隔，公开接口低频访问，不触发风控

## 安装

**油猴版（推荐先用来验证）**
1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本 → 粘贴 `dist/bili-scanner.user.js` 全部内容 → 保存
3. 打开 `search.bilibili.com` 搜索任意关键词，右下角出现控制面板

**Chrome/Edge 扩展版（正式分发用）**
1. `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选 `dist/extension/` 目录
2. 同样打开B站搜索/热门/排行榜页使用

## 使用

- 面板可调：爆文阈值（默认播放≥粉丝10倍）、最低播放量（默认5万，滤新视频噪声）、赛道关键词（默认：小说/推文/短剧/广播剧/有声/原著）
- 爆文卡片：粉红色描边 + 徽标 `▶播放 ✿粉丝 🎯倍率 ⭐词`
- **翻页累积**：数据按天持久化，翻页/复访持续累加，面板显示「本会话 X · 爆文 Y（当日累计 Z）」；「导出当日CSV」一次性导出全天数据
- **粉丝缓存**：按 UP主 缓存24小时，同一UP主多条视频只查一次粉丝数，翻页扫描明显提速
- 「清空累计」重置当日数据；「导出CSV」可直接喂给 `src/short-scanner` 做后续分析

## 项目结构

```
src/core.js              核心逻辑（环境无关，单一来源）
build.js                 构建脚本：node build.js
dist/bili-scanner.user.js  油猴发布版（自动生成，勿手改）
dist/extension/            Chrome MV3 扩展（自动生成，勿手改）
```
